03 / Terminal & Split

Shell inside,
experiments outside.

The terminal is not an emulator — it is the OS's own shell. The split is a safety zone: your main file always stays clean.

  • Select + Ctrl+C → copies. With no selection Ctrl+C sends SIGINT to the shell.
  • Ctrl+V / Shift+Insert → paste from clipboard; arrow keys walk history.
  • F5 runs any language: py, js, ts, go, rs, java, c, cpp, rb, php, lua, sh, ps1…
  • Missing runtime? The IDE asks: “Node.js is not installed. Install it?” — Yes triggers winget/apt/brew.

08 / FAQ

Good questions

Is it really fully offline?

Yes. Monaco, xterm.js, fonts and icons ship inside the package. The internet is only needed for two optional things: installing an LSP server and the AI assistant (with your own keys).

Where does my data go?

Everything lives under ~/.splash_code/: settings, session, tasks, logs. No telemetry, no analytics, no hidden requests — grep the source.

Which operating systems?

Windows 10/11 (pywinpty), macOS and Linux (ptyprocess). An exe build is produced by build_exe.py; it runs on machines without Python installed.

Can it run code on a machine without Python?

Yes. The IDE carries its own interpreter; it can also keep a portable runtime next to the exe. If a language runtime is missing (node, go…) it offers a one-click install.
